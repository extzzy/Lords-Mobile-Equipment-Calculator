# Lords Mobile Equipment Calculator

Калькулятор снаряжения для Lords Mobile: подбор предметов по слотам, расчёт грейдов, улучшения астралитом и украшений, сохранение пресетов с возможностью сравнения, экспорт в JSON.

**Демо:** https://USERNAME.github.io/lords/ _(замените после публикации)_

## Возможности

- 8 слотов снаряжения (Main-hand, Off-hand, Helmet, Armor, Legs, 3 × Accessory)
- 199 предметов из 33 сетов с реальными статами из вики Lords Mobile
- 6 грейдов (Common → Mythic) с точными игровыми множителями
- Астралит для Mythic-предметов: T0–T15
- 3 слота под украшения (jewels) на каждом предмете, 36 типов украшений
- Эффективные показатели (Войско + Армия)
- Сохранение и сравнение пресетов в `localStorage`
- Экспорт сета в JSON
- Переключатель языка RU/EN
- Скрытие «мусорных» статов (ЗАЩ, ресурсы, осадные)

## Технологии

Чистый ванильный HTML/CSS/JS. Никаких сборок, никаких зависимостей.

## Локальный запуск

Открыть `index.html` в браузере. Для корректной работы `localStorage` и `fetch` иконок предпочтительно поднять локальный HTTP-сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000/
```

## Деплой на GitHub Pages

1. Создать репозиторий на GitHub
2. В корне проекта:
   ```bash
   git init
   git add .
   git commit -m "initial commit"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```
3. На GitHub: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**
4. Через минуту приложение будет доступно по адресу `https://USERNAME.github.io/REPO/`

Все пути в проекте относительные, поэтому работает и из корня, и из подпапки.
